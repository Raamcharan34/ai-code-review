# 🤖 AI Code Review

An AI-powered code review tool that analyzes source code and identifies bugs, security issues, performance problems, and code-quality improvements.

## 🚀 Live Demo

🔗 https://ai-code-review-puce-one.vercel.app

## 📌 About the Project

AI Code Review is a web-based developer tool that uses AI to analyze source code.

Users can paste their code into the editor, select a programming language, and run an automated review.

The application provides:

- 🐛 Bug and error detection
- 🔐 Security issue analysis
- ⚡ Performance analysis
- 📊 Code quality review
- 💡 Suggested improvements
- ✨ AI-generated improved code

## 🛠️ Tech Stack

- **Frontend:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **AI:** Groq AI
- **Deployment:** Vercel
- **Version Control:** Git & GitHub
